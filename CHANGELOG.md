# Changelog

All notable changes to SoundLight are documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-13

### Added

- Independent edge-mounted HUDs for volume and built-in display brightness.
- Smooth entrance, exit, scaling, and level transitions.
- Live synchronization with macOS audio and display values.
- Adaptive symbols and colors for light, dark, and increased-contrast appearances.
- Menu bar controls with drag and accessibility support.
- Universal macOS release packaging for Apple silicon and Intel Macs.
